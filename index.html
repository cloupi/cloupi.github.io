共享网盘 · GitHub 版

所有人可上传、可下载 · 每个用户一个分支空间
使用前先点右上角「设置」填入你的 GitHub 信息。
安全提醒：Token 是你的 GitHub 密钥，任何人拿到它都能改动你的仓库。这个网页如果部署成公开网站，不要把密钥填在公共电脑上，建议仅自己使用。单文件最大 100MB，可传任意类型文件。

上传文件

输入用户名 → 选文件 → 上传。文件会存进「以用户名命名的分支」。
点击选择文件，或把文件拖到这里

浏览与下载

每个用户名 = 一个分支，点开看里面的文件，直接下载。
所有用户 分支文件
共享网盘 · 基于 GitHub API 构建 · 每个文件都会提交到你仓库的对应分支

GitHub 设置

生成方法：GitHub → Settings → Developer settings → Personal access tokens → Tokens(classic)，勾选 repo 权限。Token 只保存在你自己的浏览器里。
